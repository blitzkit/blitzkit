# BlitzKit 1.31.4

Thank you to [Mark Greene](https://github.com/Hitjack007) for your contributions this update.

## Features

- [Mark Greene] Added Peekaboo DPM
  - Your Peekaboo DPM is lower than your normal DPM if your reload is faster than 10s as you'll have to wait for the remaining 10s for you to get unspotted before you can poke and shoot
-

## Fixes

- [Mark Greene] BlitzKit Session now properly handles tanks removed from the game
- [Mark Greene] Removed the Beta badge from the Equalizer button
- Updated the background image for the Equalizer button to the actual banner of the new game mode
- [Mark Greene] The armor no longer disappears when you turn on Dynamic Armor System
- [Mark Greene] Camouflage values in Tankopedia are now more descriptive when shooting
- [Mark Greene] The contact shadows on the ground no longer grow & darken when switching between tabs

## Technical Fixes

- BlitzKit now handles the new ID system for game-modes in WoTB
- The directory which preview versions of the game are downloaded to are now created properly
  - This was the last bug standing in the way of BlitzKit Previews
  - Welcome back, BlitzKit Previews!
