# BlitzKit 1.31.0

This update massively upgrades BlitzKit's graphical fidelity (while making it faster) and updates the way BlitzKit deploys updates, speeding up future versions.

## Features

- Improved the performance of the Tank Sandbox in Tankopedia
  - Reduced the number of lights by 25%
  - Reduced the resolution of shadows by 50%
- Improved the graphical fidelity of tanks in the Tankopedia
  - Added soft contact shadows below tanks
  - Added sky and ground reflected lighting to the top and bottom of tanks
  - Removed the fog that used to darken tanks when zoomed far away
  - Made BlitzKitLand™ fade out circularly to hide the sharp edges
  - Pointed the lights 1.5m above the ground
  - This genuinely makes BlitzKit almost photo-realistic in my opinion
- Non-PBR tanks are now lit up brighter to accommodate for their dark textures

## Fixes

- Fixed a bug where the ambient occlusion map (a measure of how dark a part of a tank gets due to low light bounces) was applied to the color of the tank directly, making many tanks appear dark even in direct light
- Tanks with chinese characters now generate urls through transliteration

## Known Issues

- The flags found behind the selected tank in the tech tree section of the Tankopedia is offset incorrectly

## Technical Features

- BlitzKit can now calculate and store performance statistics and account details for up 10,000,000,000 players
  - This will help make the BlitzKit Performance tool more accurate, and play well with an upcoming, unannounced major feature

## Technical Changes

- The `production` branch now deploys updates to `blitzkit.app` instead of the `main` branch
- `robots.txt` now disables indexing of BlitzKit variants based on the environment
- The website is now compiled in "chunks" of which the `api` chunk now takes on the task of mangling what was previously stored in `assets3`
  - `assets3` will be removed in `1.31.1`, please migrate to the new `api` if you use any BlitzKit assets
- Removed the `bot` and `app` packages
- Removed Prisma
